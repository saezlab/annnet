# API reference

This section gives the exact signatures and options of the public functions and
classes of annnet. To learn the concepts, start with the [Guide](../guide/index.md).

- [API overview](api-boundary.md): all public names on one page, with links.
- The pages in the navigation give the details of each part: the graph and its
  namespaces, reading and writing files, the adapters to other graph libraries,
  and plotting.
