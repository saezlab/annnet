# Traversal and structure

The traversal methods (`neighbors`, `in_neighbors`, `out_neighbors`,
`successors`, `predecessors`) are methods of the graph:
`anet.neighbors('EGFR')`. The functions in `annnet.algorithms` answer questions
about the directed edges of a graph.
