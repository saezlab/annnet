# PyTorch Geometric

Convert a graph to and from a
[`HeteroData`](https://pytorch-geometric.readthedocs.io/en/latest/generated/torch_geometric.data.HeteroData.html)
object of [PyTorch Geometric](https://pytorch-geometric.readthedocs.io/), for
graph neural network workflows. Only what fits into tensors is exported.

::: annnet.io.pyg.from_pyg
    options:
      show_root_heading: true

::: annnet.io.pyg.to_pyg
    options:
      show_root_heading: true
